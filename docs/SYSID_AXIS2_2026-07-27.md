## Failures and limitations

- Servo temperature telemetry is unavailable through this HID controller, so
  overheat auto-pause could not measure real temperatures.
- Ubuntu's `python3-hid` binding was linked to the libusb backend, which could
  not use the permitted hidraw node. The run used the installed hidraw backend
  through `LD_PRELOAD`; the driver was updated to support Ubuntu's
  `hid.device().open_path()` API.
- The generic analyzer initially rejected the active CSV schema because it
  expected passive `vel_1/vel_2` fields. It now supports active
  `command_1/command_2` and `board_angles.csv` logs.
- `ball_visible=1` in this marble-removed run is false: HSV-only mode selected a
  static blue maze feature. Ball fields must not be used from this session;
  board-angle and command fields are unaffected.
- State messages do not yet carry source timestamps. The fitted 0.25-second lag
  is receipt-time correlation with coarse 0.106-second command sampling, not a
  validated actuator latency.
